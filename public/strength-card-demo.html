Progressive overload preview

Live output of progressive-overload.js rendered by dp-strength-card.js. Tap any card to expand the ladder, PB and set inputs. Each block below feeds the engine a different history so you can see every state and increment rule.

Increments used here: barbell +2.5kg, dumbbell +2kg, machine +2.5kg, accessory +1kg, bodyweight adds reps. A stall over 3 sessions triggers a 10% back-off. Serve this folder (for example npx serve public) so the ES module imports load.
