Daily macro overrides

Nutrition is prescribed per week. The days that actually need precision — the 30 km long run, the double, race day, a full rest day — all sit inside that one week. This adds a coach-owned override for a single date, without touching how the rest of the week works.

01

Coach · the week row

The day strip lives inside the existing Nutrition week row, under the macro cells. Dim days inherit the week. Green days are published to the athlete. Amber is a draft the athlete cannot see. A coach scanning the roster can tell at a glance that a week is not uniform.

02

Coach · the day editor

Tapping any day opens the whole week, with that day focused, so a back-to-back weekend gets set in one sitting. The weekly baseline is pinned at the top and every input shows its live delta against it, so a mistyped figure is obvious before it reaches an athlete. Values are absolute — what the athlete eats that day — never deltas, so editing the week later cannot silently move a published day.

04

The rules underneath

These are the decisions that keep it from turning into a second, competing source of truth for macros.

OwnershipCoach writes, athlete reads

Athletes never create, edit or dismiss an override. Same rule as the training prescription and the weekly sport targets.

ValuesAbsolute, not deltas

The stored number is what the athlete eats. Editing the weekly baseline later cannot silently move a day that has already been published.

ScopePurely additive

Weekly rows stay exactly as they are. No backfill of seven rows per week. A week with no overrides behaves identically to today.

LifecycleDraft, publish, soft-remove

Drafts are invisible to athletes. Removing returns the row to draft and stamps it — hard delete is rejected by the database, so history survives.

effectiveTargetsFor(date) published override for that date → use it source: coach_day else weekly nutrition_plans row → use it source: coach_week else → nothing One resolver, one place. The km target code already shows how fast two resolvers drift into showing one week two different numbers.
